# ESO-ESOUI_Helpers
Some helper tools for ESO addons, website ESOUI
e.g. detect global variables (or globally used in ESOUI sources -> but nil; missing local definition) defined in native C code, which aren't mentioned in the ESOUI API Documentation txt file.
Creadted lua list file with code line refrences where they were found can be used for other tools that need globals of ESO for comparison.

e.g. the ESOUI addon downloader and source code checker tool (with local Ollama AI support)
