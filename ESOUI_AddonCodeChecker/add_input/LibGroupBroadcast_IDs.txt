= LibGroupBroadcast IDs =
[[How_to_share_data_within_groups|LibGroupBroadcast]] is a library used by addons to share data between group members.<br>
Find the API description and usage here: [https://www.esoui.com/downloads/info1337-LibGroupBroadcastformerlyLibGroupSocket.html LibGroupBroadcast at esoui.com]<br><br>

The sent data is associated to your addon by an ID (data protocol), which has to be unique across all addons to prevent compatibility issues.<br>

== Howto register your own custom event / data protocol ==
After you wrote your code and before you upload your addon or library to ESOUI, you have to add the necessary information to the tables below.
Simply pick the next free id, update your code accordingly and edit this wiki page.

== Protocols ==
For protocols the id range is a bit larger and there are up to 512 ids available.
In order to keep ids somewhat organized, it was suggested that for now everyone should "reserve" blocks of 10 ids, so future protocols that belong to the same handler can be added later if needed. The first 10 ids are reserved for LibGroupBroadcast itself and for legacy support of specific libraries that shared data via map pings.
